Track your cycle. Manage PCOS. All in one place — private, simple, and beautiful.

Period tracking, PCOS management, symptom logging, daily check-in, habits, diet plan, PCOS score, doctor report, reminders, yoga and personal diary — all in one app.

**Live Demo:** https://ammarahmed-star.github.io/PCOS---Management---Application/

> ⚠️ This app is for awareness and tracking only. It is not a medical diagnosis. Only a doctor can diagnose PCOS with tests (Ultrasound + Hormone tests).

## ✨ Features — 13 Tabs, PRO Version

| # | Feature | What It Does |
|---|---------|--------------|
| 1 | **📊 Dashboard** | Last Period + Cycle Length → Cycle Day, Next Period, Ovulation, Days Left auto-calculate |
| 2 | **📅 Period Tracker** | Calendar — Click any date to mark Period, Prev / Next month, Clear Marks |
| 3 | **🩺 Symptoms** | 12 Symptoms — Cramps, Bloating, Mood Swings, Acne, Hair Fall, Fatigue, Headache, Back Pain, Nausea, Breast Tenderness, Cravings, Irregular Period — Click to select + Save |
| 4 | **✅ Daily Check-in** | Mood, Energy (1-10), Sleep (hrs), Water (glasses), Exercise — Daily Save |
| 5 | **🌱 Habits** | 6 Healthy Habits — Healthy Breakfast, 8 Glasses Water, 30 Min Walk, 10 Min Yoga, 7+ Hrs Sleep, No Phone Before Sleep — Mark Done + Score |
| 6 | **💡 Wellness Tips** | Diet, Movement, Sleep, When to See a Doctor |
| 7 | **📈 PCOS Score** | 6 Questions (Period, Acne, Hair Growth, Hair Fall, Weight, Tired / Mood) — Score / 18 → 🟢 Low (0-4) / 🟡 Medium (5-9) / 🔴 High (10+) + Advice |
| 8 | **📄 Doctor Report** | Generate Report → Period + Symptoms + Check-in + Habits + PCOS Score — Print / Save as PDF |
| 9 | **🥗 Diet Plan** | 7-Day Plan — Monday to Sunday — Breakfast / Lunch / Dinner / Snack + Eat More / Avoid List |
| 10 | **📈 History** | Saved Data Summary + Visual Bars + Clear All Data |
| 11 | **🔔 Reminders** | Water Goal + +1 Glass Water + Medicine / Vitamin Time + Period Reminder (Next period in X days) |
| 12 | **🧘 Yoga & Exercise** | 6 Best for PCOS — Surya Namaskar, Butterfly Pose, Cobra Pose, Cat-Cow, 30 Min Walk, Anulom Vilom |
| 13 | **📝 Diary** | Personal Notes — Date wise Save, Private |

## 🎮 How To Use

1. **Dashboard:** Set Last Period Date + Cycle Length → Save → Prediction appears
2. **Period Tracker:** Click any date on calendar to mark Period
3. **Symptoms:** Click symptoms → Save Today's Symptoms
4. **Check-in:** Fill Mood / Energy / Sleep / Water / Exercise → Save Check-in
5. **Habits:** Press Mark Done for each habit
6. **PCOS Score:** Answer 6 questions → Calculate My Score
7. **Doctor Report:** Generate Report → Print / Save as PDF → Show to doctor
8. **Diet Plan:** Select a day → See full day plan
9. **Reminders:** Set Water Goal → +1 Glass Water as you drink
10. **Diary:** Write note → Save Note
