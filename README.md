### 📈 PCOS Score — 6 Questions (Static HTML)

This version has **questions written directly in HTML**, not generated by JS — so they always visible:

1. **Are your periods irregular?** (Gap >35 days or missed often)
2. **Do you have acne / oily skin often?**
3. **Do you have unwanted hair growth?** (face / chest / back)
4. **Do you have hair fall / thinning hair?**
5. **Weight gain / difficulty losing weight?**
6. **Tired / mood swings / dark patches?**

**Scoring Logic:**
- 0-4 → 🟢 LOW RISK
- 5-9 → 🟡 MEDIUM RISK  
- 10-18 → 🔴 HIGH RISK

> ⚠️ This is not a medical diagnosis. Only a doctor can diagnose PCOS with tests (Ultrasound + Hormone tests).

### 📂 How Data is Saved (Privacy First)

All data saved as `cc_` keys in LocalStorage:
- `cc_last`, `cc_len`, `cc_marks`, `cc_symptoms_YYYY-MM-DD`, `cc_checkin_...`, `cc_habits_...`, `cc_score`, `cc_reminder`, `cc_diary_...`

No server. No login. 100% private.
